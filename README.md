# espOTA

ESP32(MicroPython) 기기가 이 저장소의 코드를 주기적으로 확인해서 스스로 업데이트하는 OTA(Over-The-Air) 배포 시스템.

## 파일
- `main.py` — OTA로 실제 배포되는 운영 코드. 와이파이 연결 → NTP 시간 동기화 → 텔레그램 기동 알림 → 5분마다 하트비트 → 10분마다 OTA 업데이트 체크. 포트폴리오 블로그(`harna0910.tistory.com`) 글 1~50번을 1~5분 랜덤 간격으로 순회하며 접속 상태를 점검하는 로직도 포함
- `main_form.py` — 더 단순한 템플릿 버전. 하트비트 + "매 정각마다 한 번" OTA 체크만 수행하는 기본 뼈대
- `version.txt` — 현재 배포된 펌웨어 버전 번호

## 동작 방식
1. 부팅 시 와이파이 연결, 시간 동기화, 텔레그램 알림
2. 정해진 주기로 GitHub의 코드를 확인해서 변경이 있으면 다운로드 후 재부팅 (`ota.check_update()`)
3. `user_task()` 함수 안에 원하는 로직(매매, 센서 읽기 등)을 자유롭게 추가 — 이 부분은 OTA 동작과 무관

> ⚠️ `▼▼▼ OTA 필수 헤더 ▼▼▼` ~ `▲▲▲ 필수 헤더 끝 ▲▲▲` 블록은 순서/내용을 바꾸면 OTA 자체가 깨질 수 있어 건드리지 않아야 함.
